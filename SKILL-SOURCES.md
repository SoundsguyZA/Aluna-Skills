- Verification Before Completion: adapted from [obra/superpowers](https://github.com/obra/superpowers), MIT. Licence retained in its folder.
- Adaptive learning: original Aluna/VERITAS procedure; pskoett/self-improving-agent was research only and not imported.
- All client profiles, records and account configuration are deliberately excluded.

This branch is a staging tree only. It is not an independent security boundary, a separate MCP endpoint, or an active customer deployment.
