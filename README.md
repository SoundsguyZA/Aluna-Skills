# Aluna Executive — Property Edition v1.0

A curated, runtime-neutral skill distribution for executive assistants serving property and professional services. This is a release staging branch of Aluna-Skills, not a separate repository or access-control boundary.

## Contents
Core: truth protocol, red-team fact checker, humanizer, verification before completion, adaptive learning, executive operations.
Property edition: commercial outcomes, site survey and proposal.
No scripts, secrets, client data, private memory, legal-fortress or engineering tools.

## Release and deployment
1. Publish only this tree to an independent repository with a default main branch. Keep licences and provenance. The upstream Aluna-Skills main branch remains the source of the original seven skills.
2. Register the independent repository with SkillsOverMCP or another approved skill delivery mechanism. Verify discovery and retrieve each of the eight skills. Verify account compatibility before promising integration.
3. In each customer's own account, configure their profile, permissions, private records and workspace, then run ACCEPTANCE.md. Never store client identity, documents, customer contact details or credentials in this shared distribution.

A standalone instructions-based assistant is the fallback for accounts without custom MCP support. See DEPLOYMENT.md.
